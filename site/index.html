Lanebench

Offline evals for freight agents. Three negotiation strategies bargain with simulated car-hauling carriers, and two parsers read the kind of texts truck drivers actually send.

Negotiation

Each scenario is a carrier with an asking rate, a hidden floor they won't go below, and a personality. Flexible carriers concede fast, firm ones barely move, flaky ones hang up after three rounds, and proud ones hang up on an insulting opening offer. Our ceiling comes from what we quoted the customer, so some loads can't be won without losing money, and walking away is the right answer.

Margin kept versus loads won

Margin kept is the total we stayed under our ceiling across clean deals. Neither number tells the whole story alone.

Reading driver texts

Messages like “dot inspection at the scale, gonna be late. eta tmrw” need to become an event, an ETA if there is one, and a flag when someone at the brokerage should step in. The dev set has 48 hand-labeled messages. The held-out set has 20 more, written separately and never used to tune anything.

Faded bar: dev set. Solid bar: held-out set.

Run it yourself with python -m lanebench. Add --llm with an ANTHROPIC_API_KEY set to score Claude on the same scenarios. Everything here is regenerated from results/results.json.
